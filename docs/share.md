# Share idea-to-mvp / شارك المهارة

## English

Have an app idea? Idea to MVP helps your coding assistant research it, ask useful questions and turn your answers into a clear plan. When you approve the build, it uses official GitHub Spec Kit to guide implementation and testing.

Get the skill and step-by-step agent installation guides:
https://github.com/eyoussef-builds/idea-to-mvp

[English infographic](images/infographic-en.png) · [Arabic infographic](images/infographic-ar.png)

## العربية

عندك فكرة تطبيق ومش عارف تبدأ؟ مهارة Idea to MVP تساعد مساعد البرمجة يبحث ويسألك أسئلة مفيدة ويحوّل إجاباتك إلى خطة واضحة. وعندما توافق على البناء، يستخدم GitHub Spec Kit الرسمي لتنظيم التنفيذ والاختبار.

المهارة ودليل التثبيت خطوة بخطوة:
https://github.com/eyoussef-builds/idea-to-mvp
